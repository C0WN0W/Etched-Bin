# Etched-Bin
把音乐存在服务器上，试听和获取直链。任何人都可以上传和删除。

做这个的初衷是玩Minecraft的Etched模组。网上的大多数直链平台都太垃圾了。。支持自动获取专辑封面，没有封面的会自动使用圆石封面（算是保留了Etched的特色了）。
